# JR 자막

재생 중인 일본어를 기기 안에서 한국어 자막으로 보여 주는 앱입니다. 설치 파일만 여기에 있습니다.

## 받기

- Android 1.0.14: [jr-subtitle-android-1.0.14.apk](https://github.com/HS2949/JR_subtitle-release/releases/download/v1.0.14/jr-subtitle-android-1.0.14.apk)
- Windows 1.0.14: [jr-subtitle-windows-1.0.14.zip](https://github.com/HS2949/JR_subtitle-release/releases/download/v1.0.14/jr-subtitle-windows-1.0.14.zip)

## 설치

Android는 APK를 열고 설치합니다. Android 13 이상에서는 다른 앱 위에 표시하려면 앱 정보에서 제한된 설정을 허용해야 할 수 있습니다. 소리를 들으려면 화면 공유를 허용해야 하며, 화면 그림은 저장하지 않습니다.

Windows는 압축을 푼 폴더에서 `jr_subtitle.exe`를 실행합니다. DLL 파일을 같은 폴더에 두세요.

처음 실행할 때 인식과 번역 모델을 받습니다. 일부 앱과 복사 방지 영상은 소리가 들리지 않습니다.
